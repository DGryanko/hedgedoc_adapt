## Технічні рішення

### Проблема: Docker без iptables в WSL2
**Рішення:** Використання userland-proxy + фіксовані IP адреси

### Проблема: DNS не працює в контейнерах
**Рішення:** extra_hosts + прямі IP адреси в connection string

### Проблема: Порти не проксіюються
**Рішення:** Увімкнення userland-proxy в daemon.json
