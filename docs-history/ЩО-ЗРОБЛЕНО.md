### Зараз (Windows + WSL2)

```
Подвійний клік на: hedgedoc-clean/start-hedgedoc.bat
```

### Для Raspberry Pi

1. Скопіюй папку `hedgedoc-clean` на Raspberry Pi
2. Прочитай `SETUP-RASPBERRY.md`
3. Встанови Docker
4. Запусти `./start-hedgedoc.sh`

### Очистити проект

```
Подвійний клік на: cleanup-project.bat
```
