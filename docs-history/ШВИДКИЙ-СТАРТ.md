# 🚀 Швидкий старт HedgeDoc

## Для тебе (Windows + WSL2 Debian)

### Зараз (вже налаштовано)

```
Подвійний клік на: hedgedoc-clean/start-hedgedoc.bat
```

Відкрий: http://localhost:3000

### Після перезавантаження Windows

```
Подвійний клік на: hedgedoc-clean/start-hedgedoc.bat
```

Батнік автоматично:
1. Запустить Docker daemon
2. Перевірить конфігурацію
3. Запустить HedgeDoc
4. Покаже статус

### Зупинка

```
Подвійний клік на: hedgedoc-clean/stop-hedgedoc.bat
```

## Для Raspberry Pi Zero 2W

### Перший раз (з нуля)

1. Прочитай: `hedgedoc-clean/SETUP-RASPBERRY.md`
2. Встанови Raspberry Pi OS (64-bit)
3. Встанови Docker
4. Скопіюй папку `hedgedoc-clean` на Raspberry Pi
5. Запусти:

```bash
cd ~/hedgedoc-clean
chmod +x *.sh
./start-hedgedoc.sh
```

6. Відкрий: http://IP_RASPBERRY_PI:3000

### Наступні рази

```bash
cd ~/hedgedoc-clean
./start-hedgedoc.sh
```

### Автозапуск після перезавантаження

```bash
sudo nano /etc/systemd/system/hedgedoc.service
```

Вставити (зміни `pi` на свого користувача):

```ini
[Unit]
Description=HedgeDoc
Requires=docker.service
After=docker.service

[Service]
Type=oneshot
RemainAfterExit=yes
WorkingDirectory=/home/pi/hedgedoc-clean
ExecStart=/usr/bin/docker compose up -d
ExecStop=/usr/bin/docker compose down
User=pi

[Install]
WantedBy=multi-user.target
```

Увімкнути:

```bash
sudo systemctl enable hedgedoc.service
sudo systemctl start hedgedoc.service
```

## Корисні команди

### Перевірити статус

```bash
# Windows
wsl -d Debian bash -c "cd /mnt/f/GitHub/hedgedoc/hedgedoc-clean && sudo docker compose ps"

# Linux/Raspberry Pi
cd ~/hedgedoc-clean
sudo docker compose ps
```

### Подивитись логи

```bash
# Windows
wsl -d Debian bash -c "cd /mnt/f/GitHub/hedgedoc/hedgedoc-clean && sudo docker compose logs -f"

# Linux/Raspberry Pi
cd ~/hedgedoc-clean
sudo docker compose logs -f
```

### Перезапустити

```bash
# Windows
wsl -d Debian bash -c "cd /mnt/f/GitHub/hedgedoc/hedgedoc-clean && sudo docker compose restart"

# Linux/Raspberry Pi
cd ~/hedgedoc-clean
sudo docker compose restart
```

### Backup бази даних

```bash
# Windows
wsl -d Debian bash -c "cd /mnt/f/GitHub/hedgedoc/hedgedoc-clean && sudo docker compose exec database pg_dump -U hedgedoc hedgedoc > backup.sql"

# Linux/Raspberry Pi
cd ~/hedgedoc-clean
sudo docker compose exec database pg_dump -U hedgedoc hedgedoc > backup.sql
```

## Проблеми?

1. Перевір: `hedgedoc-clean/TROUBLESHOOTING.md`
2. Перевір логи: `docker compose logs`
3. Перезапусти: `docker compose restart`
