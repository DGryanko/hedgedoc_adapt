## Як використовувати

### Зараз (Windows + WSL2)
```
Подвійний клік на: hedgedoc-clean/start-hedgedoc.bat
```

### Для Raspberry Pi
1. Скопіюй папку `hedgedoc-clean` на Raspberry Pi
2. Прочитай `hedgedoc-clean/SETUP-RASPBERRY.md`
3. Запусти `./start-hedgedoc.sh`

### Перенесення на інший комп'ютер
Просто скопіюй папку `hedgedoc-clean` - Docker образи завантажаться автоматично.
