## Технічні особливості

### WSL2 без iptables
Через відсутність iptables в WSL2 Debian використовуються:
- Фіксовані IP адреси для контейнерів
- `extra_hosts` для DNS резолвінгу
- Пряме підключення до сервісів через IP

Це нормальна практика для WSL2 і працює стабільно.

### Docker daemon
Docker daemon потрібно запускати вручну після кожного перезапуску WSL:
```bash
wsl -d Debian bash -c "sudo dockerd > /dev/null 2>&1 &"
```

Це автоматично робиться в батниках.

## Backup

### Що потрібно бекапити:
1. База даних PostgreSQL
2. Завантажені файли (Docker volume)
3. Конфігурація docker-compose.yml

### Як зробити backup бази даних:
```bash
wsl -d Debian bash -c "cd /mnt/f/GitHub/hedgedoc/hedgedoc-1x && sudo docker compose exec database pg_dump -U hedgedoc hedgedoc > backup.sql"
```

## Troubleshooting

### Контейнери не запускаються
```bash
# Перевірити логи
wsl -d Debian bash -c "cd /mnt/f/GitHub/hedgedoc/hedgedoc-1x && sudo docker compose logs"

# Перезапустити Docker daemon
wsl --shutdown
# Потім знову запустити батник
```

### Порт зайнятий
```bash
# Перевірити, що використовує порт 3000
wsl -d Debian bash -c "sudo netstat -tulpn | grep 3000"

# Зупинити старі контейнери
wsl -d Debian bash -c "sudo docker ps -a"
wsl -d Debian bash -c "sudo docker stop <container_id>"
```

### База даних не підключається
```bash
# Перевірити статус бази даних
wsl -d Debian bash -c "cd /mnt/f/GitHub/hedgedoc/hedgedoc-1x && sudo docker compose ps"

# Перевірити логи бази даних
wsl -d Debian bash -c "cd /mnt/f/GitHub/hedgedoc/hedgedoc-1x && sudo docker compose logs database"
```

## Корисні команди

```bash
# Статус контейнерів
wsl -d Debian bash -c "cd /mnt/f/GitHub/hedgedoc/hedgedoc-1x && sudo docker compose ps"

# Логи в реальному часі
wsl -d Debian bash -c "cd /mnt/f/GitHub/hedgedoc/hedgedoc-1x && sudo docker compose logs -f"

# Перезапустити контейнери
wsl -d Debian bash -c "cd /mnt/f/GitHub/hedgedoc/hedgedoc-1x && sudo docker compose restart"

# Видалити все і почати заново
wsl -d Debian bash -c "cd /mnt/f/GitHub/hedgedoc/hedgedoc-1x && sudo docker compose down -v"
```
