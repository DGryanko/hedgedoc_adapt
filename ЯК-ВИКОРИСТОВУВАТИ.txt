═══════════════════════════════════════════════════════════════
  ДЛЯ НОВОЇ МАШИНИ (Windows + WSL2)
═══════════════════════════════════════════════════════════════

1. Скопіюй папку hedgedoc-clean/ на нову машину

2. Прочитай інструкцію:
   → hedgedoc-clean/SETUP-WSL.md

3. Встанови WSL2 + Debian + Docker (20-30 хв)

4. Запусти:
   → Подвійний клік на start-hedgedoc.bat

═══════════════════════════════════════════════════════════════
  ДЛЯ RASPBERRY PI ZERO 2W
═══════════════════════════════════════════════════════════════

1. Скопіюй папку hedgedoc-clean/ на Raspberry Pi

2. Прочитай інструкцію:
   → hedgedoc-clean/SETUP-RASPBERRY.md

3. Встанови Docker (30-60 хв)

4. Запусти:
   → cd hedgedoc-clean
   → ./start-hedgedoc.sh

═══════════════════════════════════════════════════════════════
  ЩО ПОТРІБНО ДЛЯ ВСТАНОВЛЕННЯ

Тільки папка hedgedoc-clean/ містить:

✅ docker-compose.yml       - конфігурація
✅ start-hedgedoc.bat       - запуск Windows
✅ stop-hedgedoc.bat        - зупинка Windows
✅ start-hedgedoc.sh        - запуск Linux/Raspberry Pi
✅ stop-hedgedoc.sh         - зупинка Linux/Raspberry Pi
✅ SETUP-WSL.md            - інструкція WSL2 з нуля
✅ SETUP-RASPBERRY.md      - інструкція Raspberry Pi з нуля
✅ TROUBLESHOOTING.md      - вирішення проблем
✅ README.md               - загальна інформація

Docker образи завантажаться автоматично при першому запуску!
